# Recipe Explorer

# Description

Recipe Explorer is a responsive React web app that lets users discover, search, and browse recipes in a clean and modern interface. It features a sleek landing section, categorized recipe grid, a simple authentication modal system for login and registration, and an about page. The project was built to practice full-stack development fundamentals — focusing on UI design, routing, and smooth deployment.

# Tech Stack

Frontend Framework: React (with Hooks)
Routing: React Router DOM v7
Build Tool: Vite
Styling: Custom CSS
Deployment: GitHub Pages (via gh-pages package)
Version Control: Git + GitHub
